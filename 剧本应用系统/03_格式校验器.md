# ✅ 剧本格式校验器

## 校验规则

### 1. 标题格式
```
✅ 正确：第1集：地铁偶遇
❌ 错误：第1集【地铁偶遇】
❌ 错误：第一集：地铁偶遇
❌ 错误：第一章：地铁偶遇
```

### 2. 结尾格式
```
✅ 正确：
第1集完


❌ 错误：
第1集完【完】
第1集完（完结）
第1集·完
```

### 3. 禁止字符
- ❌ 禁止"耀"字
- ❌ 禁止"曜"字
- ❌ 禁止【】括号
- ❌ 禁止（）括号（仅用于公式时除外）

### 4. 字数检查
- 每集正文≥500字
- 对话≤15字/句

### 5. 爽点检查
- 每集≥3爽点
- 每集≥1甜点

## 校验脚本

### Python校验脚本

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
剧本格式校验器
用法: python validate_drama.py <剧本文件路径>
"""

import re
import sys
from pathlib import Path


def validate_drama(filepath):
    """校验剧本文件"""
    
    with open(filepath, 'r', encoding='utf-8') as f:
        content = f.read()
    
    issues = []
    
    # 1. 检查禁止字符
    if '耀' in content:
        issues.append("❌ 发现禁止字符: '耀'")
    if '曜' in content:
        issues.append("❌ 发现禁止字符: '曜'")
    if '【' in content or '】' in content:
        issues.append("❌ 发现禁止符号: 【】")
    
    # 2. 检查集数格式
    episodes = re.findall(r'第\d+集[：:]', content)
    for ep in episodes:
        if '【' in ep or '】' in ep:
            issues.append(f"❌ 集标题包含【】: {ep}")
    
    # 3. 检查结尾格式
    endings = re.findall(r'第\d+集完', content)
    for end in endings:
        # 检查后面是否有多余字符
        idx = content.find(end)
        after = content[idx+len(end):idx+len(end)+10]
        if after.strip() and not after.startswith('\n\n'):
            issues.append(f"⚠️ 结尾格式可能有误: {end}{after}")
    
    # 4. 检查单集字数
    ep_blocks = re.split(r'(?=第\d+集[：:])', content)
    for block in ep_blocks:
        if re.match(r'第\d+集[：:]', block):
            # 计算正文长度（排除标题和结尾）
            lines = block.strip().split('\n')
            text_lines = [l for l in lines if not l.startswith('第') and not l.endswith('集完')]
            text_len = sum(len(l) for l in text_lines)
            if text_len < 500:
                issues.append(f"⚠️ 单集字数不足: {len(text_lines)}行, {text_len}字")
    
    # 5. 检查对话长度
    dialogues = re.findall(r'[：:][^\n]{1,200}', content)
    long_dialogues = [d for d in dialogues if len(d) > 15 and not any(c in d for c in '，。！？、；：')]
    if long_dialogues:
        issues.append(f"⚠️ 发现长对话（>15字）: {len(long_dialogues)}处")
    
    # 输出结果
    print(f"\n{'='*50}")
    print(f"剧本校验结果: {filepath}")
    print(f"{'='*50}\n")
    
    if not issues:
        print("✅ 校验通过！格式符合要求。")
        return True
    else:
        print(f"发现 {len(issues)} 个问题:\n")
        for issue in issues:
            print(f"  {issue}")
        return False


if __name__ == '__main__':
    if len(sys.argv) < 2:
        print("用法: python validate_drama.py <剧本文件路径>")
        sys.exit(1)
    
    filepath = sys.argv[1]
    validate_drama(filepath)
```

## 常见问题修复

### 问题1：发现"耀"字
**修复**：全局替换为其他同义字
- 耀眼 → 闪耀 / 灿烂 / 夺目
- 耀目 → 瞩目 / 惊艳
- 光耀 → 光辉 / 璀璨

### 问题2：单集字数不足
**修复**：
- 增加场景描写
- 扩展动作细节
- 补充心理活动（转化为表情/动作）

### 问题3：对话过长
**修复**：
- 拆分长句
- 用动作打断对话
- 用旁白替代解释性台词

### 问题4：缺少爽点
**修复**：
- 在冲突高潮处增加打脸情节
- 增加实力展示场景
- 加入萌宝/配角助攻
