# 🎬 短剧/漫剧剧本编写应用系统

> 一套完整的短剧、漫剧剧本创作工具，支持从零生成和小说改编两种模式。

---

## 快速开始

### 方式一：要素生成（适合原创故事）

```
你：我要创作一部短剧

我：你想用哪种方式创作？
  A. 要素生成 — 告诉我故事的核心要素，我帮你从零创作
  B. 小说改编 — 你有现成的小说，我帮你改编成剧本

你：A

我：[展示输入模板]

你：[填写故事要素]

我：[生成完整剧本 + 所有配套文件]
```

### 方式二：小说改编（适合已有素材）

```
你：帮我把《XXX》小说改编成短剧剧本

我：[分析小说结构 → 制定改编策略 → 生成剧本]

你：[验收]

我：[修改 → 推送GitHub]
```

## 输入模板

### 基础信息
```markdown
- 剧名：《XXX》
- 类型：都市甜宠/玄幻重生/战神逆袭/悬疑推理/历史穿越/漫剧...
- 集数：[20-60集]
- 目标平台：红果短剧/抖音/快手/...
```

### 故事设定
```markdown
- 背景：现代都市/古代王朝/修仙世界/未来科幻/...
- 世界观：[简短描述，50字以内]
- 核心风格：爽文/虐恋/搞笑/正剧/轻松/...
```

### 主角设定
```markdown
## 男主
- 姓名：
- 身份/职业：
- 性格标签：[3-5个关键词]
- 核心能力/金手指：[如有]
- 外貌特征：[简短描述]

## 女主
- 姓名：
- 身份/职业：
- 性格标签：[3-5个关键词]
- 成长弧线：[从什么状态成长为什么状态]
- 外貌特征：[简短描述]

## 反派
- 姓名：
- 动机：
- 与主角关系：
- 结局走向：[洗白/下线/惨败/...]
```

### 故事大纲
```markdown
[详细描述，建议500-1000字]
包含：开篇钩子、主要矛盾、转折点、高潮、结局
```

## 格式规范（必须遵守）

### ✅ 正确格式
```markdown
第1集：地铁偶遇

江城早高峰，地铁二号线拥挤如沙丁鱼罐头。

林缘被人群挤进车厢时，手里还攥着半杯豆浆。

"让一让。"

"排队懂吗？"

第1集完


```

### ❌ 错误格式
```markdown
第1集【地铁偶遇】    ← 禁止【】
第一集：地铁偶遇     ← 不能用"第一"
第一章              ← 不是章节制

（结尾有额外文字）   ← 只能写"第X集完"
```

### 核心规则
- 标题：`第X集：集名`（无括号）
- 结尾：`第X集完`（独立一行，无【】）
- 对话：≤15字/句
- 字数：每集≥500字
- 爽点：每集≥3爽点+1甜点
- 禁止："耀/曜"、【】括号
