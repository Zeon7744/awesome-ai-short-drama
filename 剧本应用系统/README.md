# 🎬 短剧/漫剧剧本编写应用系统

## 系统概述

本系统支持两种创作模式：
- **模式A：要素生成** — 输入故事要素，自动生成完整剧本
- **模式B：小说改编** — 上传小说，自动改编为剧本

---

## 一、模式A：要素生成剧本

### 1.1 输入模板

```markdown
## 基础信息
- 剧名：《XXX》
- 类型：都市甜宠/玄幻重生/战神逆袭/悬疑推理/历史穿越/漫剧...
- 集数：[20-60集]
- 目标平台：红果短剧/抖音/快手/...

## 故事设定
- 背景：[现代都市/古代王朝/修仙世界/未来科幻/...]
- 世界观：[简短描述，50字以内]
- 核心风格：爽文/虐恋/搞笑/正剧/轻松/...

## 主角设定
### 男主
- 姓名：
- 身份/职业：
- 性格标签：[3-5个关键词]
- 核心能力/金手指：[如有]
- 外貌特征：[简短描述]

### 女主
- 姓名：
- 身份/职业：
- 性格标签：[3-5个关键词]
- 成长弧线：[从什么状态成长为什么状态]
- 外貌特征：[简短描述]

### 主要配角
- [配角1姓名]：[身份]，[性格标签]
- [配角2姓名]：[身份]，[性格标签]

### 反派设定
- 姓名：
- 动机：
- 与主角关系：
- 结局走向：[洗白/下线/惨败/...]

## 核心冲突
一句话概括主线矛盾（例：豪门阴谋 vs 草根逆袭）

## 故事大纲
[详细描述故事情节，建议500-1000字]
包含：
- 开篇钩子（抓眼球的第一场）
- 主要矛盾展开
- 关键转折点
- 高潮设计
- 结局走向

## 特殊要求
- [可选：特定场景、特殊情节、风格偏好等]
```

### 1.2 输出产物

```
短剧项目/{剧名}/
├── {剧名}_完整剧本.md      # 完整剧本正文
├── {剧名}_角色表.md         # 角色档案与关系图
├── {剧名}_分集大纲.md       # 每集一句话概括
└── {剧名}_爽点清单.md       # 每集爽点/甜点统计
```

## 二、模式B：小说改编剧本

### 2.1 输入要求

用户提供：
- 小说完整文本（Markdown格式）
- 目标集数建议
- 重点改编章节（可选）

### 2.2 改编流程

```
小说原文 → 结构拆解 → 爽点提取 → 对话压缩 → 格式规范 → 成品输出
```

#### 步骤详解

**Step 1：结构拆解**
- 分析小说章节数量和内容密度
- 映射到目标集数（每集约1500-2000字小说内容）
- 确定每集的核心场景

**Step 2：爽点提取**
- 识别原文中的爽点、泪点、甜点
- 确保每集≥3爽点+1甜点
- 调整节奏，避免平铺直叙

**Step 3：对话压缩**
- 长对话压缩至≤15字/句
- 保留核心信息和情绪张力
- 用动作描写替代冗长对白

**Step 4：格式规范**
- 标题：第X集：集名
- 结尾：第X集完
- 无【】括号
- 无"耀/曜"字眼
- 系统提示用"叮！"

### 2.3 输出产物

```
短剧项目/{剧名}/
├── {剧名}_改编说明.md    # 改编策略与取舍说明
├── {剧名}_完整剧本.md     # 改编后剧本
├── {剧名}_角色表.md       # 角色档案
└── {剧名}_分集大纲.md     # 每集概括
```

---

## 三、格式规范（必须遵守）

### 3.1 标题格式
```markdown
第X集：集名

（空一行）
正文内容...
（空一行）
第X集完

（空两行）
```

### 3.2 对话规范
- 每句对话≤15字
- 对话独立成行
- 不用引号包裹对话
- 用动作描写承接情绪

### 3.3 禁止事项
- ❌ 禁止出现"耀/曜"任何字眼
- ❌ 禁止使用【】括号
- ❌ 禁止使用"第X幕"或"第X季"标记
- ❌ 禁止单集字数<500字
- ❌ 禁止单集爽点<3个

### 3.4 必含元素
- ✅ 每集≥3爽点
- ✅ 每集≥1甜点
- ✅ 每集有明确冲突推进
- ✅ 每集结尾有悬念钩子

## 五、使用流程

### 快速生成（模式A）

```
1. 填写输入模板（复制上方模板）
2. 发送给我
3. 我会：
   - 分析要素，规划集数结构
   - 生成完整剧本
   - 输出所有产物文件
   - 保存到短剧项目/{剧名}/目录
4. 你验收，提出修改意见
5. 我调整后推送GitHub
```

### 小说改编（模式B）

```
1. 提供小说文本（可直接粘贴或上传文件）
2. 告知目标集数
3. 我会：
   - 分析小说结构
   - 提取爽点场景
   - 改编为剧本格式
   - 输出所有产物文件
4. 你验收
5. 我调整后推送GitHub
```
