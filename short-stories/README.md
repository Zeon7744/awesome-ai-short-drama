## 改编规范

- 每篇8000-15000字，完整三幕结构
- 视觉化写法，场景描写明确，适合AI视频生成
- 保留核心爽点和名场面，砍掉支线
- 对话简短有力，每句≤15字
- 每段至少1个爽点/钩子
- 禁止出现"耀/曜"字
