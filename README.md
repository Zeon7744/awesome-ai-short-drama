## 简介

AI 短剧创作资源合集，包含 IP 大纲、分集剧本、角色标签、AI 工具推荐等内容。

## 内容统计

- 500+ IP 大纲模板
- 200+ 分集剧本
- 100+ 角色标签
- AI 工具推荐清单
- 变现案例分析

## 目录结构

```
awesome-ai-short-drama/
├── ips/           # IP 大纲
├── scripts/       # 分集剧本

├── tools/         # AI 工具推荐

```
