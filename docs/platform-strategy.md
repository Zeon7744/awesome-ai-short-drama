# 红果平台投稿运营指南

> 从投稿到爆款：完整运营策略

---

## 平台基础

### 红果短剧特点

| 特点 | 说明 |
|------|------|
| 时长 | 1-2分钟/集 |
| 集数 | 80-100集聚合一部 |
| 受众 | 下沉市场为主，女性占比高 |
| 付费点 | 前20集免费，后续解锁 |
| 分成 | 创作者与平台分成 |

### 投稿门槛

- 剧本需符合平台规范
- 禁止元素：耀、曜、敏感话题
- 对话长度限制
- 爽点密度要求

## 投稿流程

### 第一步：剧本合规检查

使用工具检查：
1. 格式校验器
2. 爽点分析器
3. 平台合规检查

### 第二步：选题策划

**热门题材：**

| 题材 | 热度 | 竞争度 | 建议 |
|------|------|--------|------|
| 豪门复仇 | ⭐⭐⭐⭐⭐ | 高 | 差异化切入 |
| 战神归来 | ⭐⭐⭐⭐⭐ | 高 | 新设定 |
| 甜宠 | ⭐⭐⭐⭐ | 中 | 强人设 |
| 悬疑 | ⭐⭐⭐ | 低 | 蓝海机会 |

### 第三步：标题设计

**公式：**
```
标题 = 身份反差 + 核心冲突 + 情绪词
```

**示例：**
- "总裁的替身前妻"
- "战神失忆后被村姑捡回家了"
- "重生劫奴"

### 第四步：封面选择

- 人物特写
- 冲突场景
- 情绪张力

## 运营策略

### 发布时间

| 时段 | 受众 | 效果 |
|------|------|------|
| 早8-9点 | 通勤人群 | 中等 |
| 午12-13点 | 午休用户 | 良好 |
| 晚20-22点 | 主力时段 | 最佳 |
| 深夜22-24点 | 追剧党 | 高粘性 |

### 更新频率

- 日更：稳定流量
- 周更3集：测试期
- 周更5集：冲榜期

### 互动运营

- 回复评论
- 引导讨论
- 收集反馈

---

## 数据指标

### 核心指标

| 指标 | 意义 | 优秀值 |
|------|------|--------|
| 完播率 | 内容吸引力 | >60% |
| 付费转化率 | 商业价值 | >5% |
| 分享率 | 传播潜力 | >3% |
| 复看率 | 内容质量 | >10% |

### 数据分析

- 第3集流失高 → 开头不够吸引
- 第10集付费低 → 爽点不够密集
- 分享率高 → 有爆款的潜质

---

## 爆款要素

### 内容层面

1. **强开局**：前3集定生死
2. **高密度爽点**：每集≥3个
3. **情绪曲线**：压抑→反转→释放
4. **人设鲜明**：主角有记忆点

### 运营层面

1. **发布时间**：晚8-10点
2. **更新频率**：日更
3. **封面标题**：高点击率
4. **互动运营**：提升粘性

## 常见问题

### Q: 如何提高完播率？

A: 
- 前3集密集爽点
- 每集结尾留钩子
- 控制单集时长

### Q: 如何提升付费转化？

A:
- 第10集设置大爽点
- 反派压迫感足够
- 反转预期强烈

### Q: 什么题材容易火？

A:
- 豪门复仇（持续热门）
- 战神归来（竞争激烈）
- 悬疑（蓝海机会）

---

## 平台规范要点

### 禁止元素

- 禁止字符：耀、曜
- 禁止括号：【、】
- 敏感话题：政治、暴力、色情
- 价值观问题

### 格式要求

- 标题格式：第X集：集名
- 结尾格式：第X集完
- 对话长度：≤15字
- 禁止长段落

---

> 📌 **记住：** 内容是根本，运营是放大器。好内容 + 好运营 = 爆款潜力。
